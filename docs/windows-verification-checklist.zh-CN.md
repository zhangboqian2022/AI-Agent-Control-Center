# Windows 真机冒烟清单 — AACC

只记录实际观察结果；未勾选项不代表兼容性承诺。

环境：Windows 10+，Python 3.12+，uv。

- [ ] **构建**：`scripts\build_windows.ps1` 执行成功，产物 `dist\AACC\AACC.exe` 存在
- [ ] **启动**：双击 `AACC.exe`，SmartScreen 提示后选择“更多信息 → 仍要运行”，面板出现并驻留托盘
- [ ] **发现会话**：运行中的 kimi / codex 会话被自动发现并显示状态灯
- [ ] **卡片聚焦**：右键“切换到任务”能聚焦目标终端窗口（窗口标题匹配）
- [ ] **按键注入**：白名单按键（Enter / Esc / 方向键 / Ctrl+C / 1 / 2）注入目标窗口生效
- [ ] **文本注入**：文本注入目标窗口内容正确
- [ ] **语音**：Win+H 语音输入在目标窗口可用
- [ ] **热键**：全局热键唤起面板（F13–F20 需 Fn 层映射的键盘确认映射后可用）
- [ ] **托盘**：面板最小化/隐藏后能从托盘恢复
- [ ] **额度条**：Kimi 额度条正确渲染（完成一次设备授权后）
- [ ] **设置页**：设置页各项（置顶、API 凭证重置等）可用且持久化
