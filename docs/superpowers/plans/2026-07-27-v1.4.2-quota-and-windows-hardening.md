# AACC 1.4.2 Quota and Windows Hardening Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver the approved A-format quota rows on macOS and Windows, make Codex weekly quota available without a recent task, expose Kimi's monthly quota honestly, and close the confirmed Windows release-gate gaps.

**Architecture:** Keep quota data acquisition independent from Qt: a bounded Codex app-server client becomes the primary reader and composes with the existing local-session reader as fallback; Kimi parsing exposes three explicitly named windows. Both GUI strips consume immutable snapshots through the existing services and render a shared four-column metric grid. A shared atomic-file helper applies POSIX modes or Windows ACLs before publication, while CI exercises the same tests, types, audits, and native package builds on both platforms.

**Tech Stack:** Python 3.12+, PySide6, httpx, PyInstaller, pytest/pytest-qt, Ruff, mypy strict, GitHub Actions, PowerShell, Windows `icacls`.

## Global Constraints

- Follow red-green-refactor: add a focused failing test, run it and record the expected failure, make the smallest implementation, then rerun the focused test.
- Preserve all unrelated user changes. Use `apply_patch` for source and documentation edits.
- Codex accepts only a future 10,080-minute weekly window; never display its five-hour limit.
- Kimi renders exactly `5H`, `WEEK`, `MONTH`, in that order. Missing data displays `--`, never inferred `0%`.
- Visible reset text is absolute local time in `M月D日 HH:mm 重置` form. Tooltips may also contain countdowns.
- Do not add the rejected Windows hidden imports, weaken placeholder-token checks, duplicate existing GUI rebuild guards, or change foreground-lock behavior.
- Do not create tag `v1.4.2` or a GitHub release until the Windows real-machine and multi-user ACL gates are signed off.
- Commit after each task with the specified message so changes remain reviewable.

def format_quota_reset(
    reset_at: datetime | None,
    *,
    local_zone: tzinfo | None = None,
) -> str:
    if reset_at is None:
        return "--"
    local = reset_at.astimezone(local_zone)
    return f"{local.month}月{local.day}日 {local.hour:02d}:{local.minute:02d} 重置"

class CompositeCodexQuotaReader:
